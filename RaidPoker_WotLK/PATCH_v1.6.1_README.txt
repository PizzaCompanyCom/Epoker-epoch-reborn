Raid 5-Card Poker WotLK v1.6.1 — Automatic Busted Status
Compatible with WoW 3.3.5a / TrinityCore.

- After each completed hand, players with 0g 0s automatically become Busted.
- All-in players are NOT marked Busted while the hand is running; settlement occurs first.
- Game Master setting a player's balance to zero automatically marks them Busted.
- Game Master replenishing a Busted player's balance automatically returns them to Playing.
- Sitting Out remains a separate manual status.
- Existing manual Busted / Playing controls remain available.
- English interface and existing v1.6.0 assets are preserved.
