**EpokerWoW Raid v2.2.0**

EpokerWoW Raid is a multiplayer poker addon for World of Warcraft 3.3.5a (TrinityCore), designed for playing poker with friends in a raid group.

The addon features two game modes: 5-Card Draw and The Barrens Hold'em (Texas Hold'em rules).

**Key Features**

Multiplayer poker with synchronized gameplay.

Solo mode with AI opponents.

Warcraft-themed poker tables and cards.

**Virtual Gold/Silver betting system.**

Game Master controls and player management.

Player balances, statistics, and game history.

Customizable settings, sounds, and interface.

All bets use virtual currency — no actual in-game gold is transferred automatically.

Version: 2.1.0
Compatibility: World of Warcraft 3.3.5a (TrinityCore)

Main Buttons

**Table Controls**

Create Table — Create a new poker table.

Join Table — Join an existing poker table.

Leave Table — Leave the current poker table.

Poker Table — Open the visual poker table.

Player Management — Manage player balances and participation.

Transfer GM — Transfer Game Master privileges to another player.

**Gameplay**

Deal — Start a new poker hand.
Check — Pass the action without betting.
Call — Match the current bet.
Bet — Place a bet.
Raise — Increase the current bet.
Fold — Discard your hand and leave the current round.
All-In — Bet your entire remaining balance.
Exchange — Replace selected cards (5-Card Draw).
Next Phase — Advance to the next stage of the hand (Hold'em).

**Player Management**

Set Balance — Set a player's virtual Gold/Silver balance.
Sit Out — Temporarily exclude a player from future hands.
Sit In — Return a player to active participation.
Default Stack / Apply — Set the starting balance for new players.
Additional Controls
Settings — Configure the addon interface and sounds.
Help — View poker rules and instructions.
Statistics — View player statistics.
History — Review previous games and administrative actions.
Reset All — Reset saved poker data.

**Supported Commands**

/poker — Open the addon.

/poker open — Open the main poker window.

/poker settings — Open addon settings.

/poker help — Display available commands and help.

/poker reseticon — Reset the addon icon position.

/poker resetall — Reset all saved poker data.
